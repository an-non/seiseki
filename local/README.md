# ローカル実行環境(声析 v0.11.0-local)

ブラウザ上で声析を動かし、データを保存して統計グラフを検証するための Vite 構成です。

## 起動

Node.js(18以上)が必要です。このフォルダで:

```
npm install
npm run dev
```

ブラウザが自動で開きます(開かない場合は http://localhost:3000)。

## 構成

- `index.html` … `/src/main.jsx` を読み込むだけの入口。
- `src/main.jsx` … **ローカル実行の要**。①`window.storage` を localStorage 実装で定義し、②その後にアプリを動的importして `<div id="root">` に描画する。この順序が重要(App.jsx は読み込み時点で `window.storage` を参照するため)。
- `src/App.jsx` … アプリ本体。`../app/seiseki.jsx` のコピー(`core/` の3ファイルを連結したもの)。

コードを修正する場合は、正本である `core/head.jsx` `core/logic.js` `core/ui.jsx` を編集し、再連結して両方に反映します:

```
cat core/head.jsx core/logic.js core/ui.jsx > app/seiseki.jsx
cp app/seiseki.jsx local/src/App.jsx
```

## データの保存先と検証

回答・設問・同意文・集計は、すべてブラウザの localStorage にキー接頭辞 `pqx1:` で保存されます。リロードしても残ります。

- **統計グラフの検証手順**: 「管理」タブ → 合言葉 `admin` → 「デモデータ投入(9件)」→「ダッシュボード」タブ。分布・属性クロス集計・グループ別パラメータ・時系列トレンド・イデオロギー分布・トピック・対象別統計が表示されます。デモの回答日時は約30日に分散しているため、時系列も折れ線が描かれます。
- **手動で回答を足す**: 「回答する」タブから送信。AI解析はローカルでは失敗するため(下記)、エラー画面で「簡易推定で保存」を選ぶと保存され、件数・分布・クロス集計・時系列に反映されます。
- **データを消す**: 管理タブの「デモデータのみ削除」「全削除」、または開発者ツール(F12)→ Application → Local Storage で `pqx1:` のキーを削除。
- localStorage はブラウザ・端末ごとに独立です。他端末とデータは共有されません(共有には本番構成=サーバー+DBへの移行が必要)。

## 既知の制約: AI解析はローカルでは動かない

`callAI` はブラウザから `https://api.anthropic.com` を直接呼ぶ実装で、ローカルでは APIキーが無く、CORS でも弾かれます。したがって「AI解析して送信」は失敗し、「簡易推定で保存」へのフォールバックになります(パラメータは中立の固定値、意見チャンクは空)。

デモデータ(9件)は解析済みの結果を含むため、**AI無しでも全グラフの検証が可能**です。恒久的な解決は、`callAI` をルールベース解析エンジンに差し替えるか、サーバー経由にすることです(`docs/PRODUCTION-DESIGN.md`)。
