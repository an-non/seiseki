## この時点で成立したもの

- 5,400入力から表記差重複400件を統合し、5,000固有ノードを表示する。
- 従来のseed付き相関モードと、Bell型論理ペアの量子式モードを比較できる。
- 観測結果から最大3件の原文要素を構造的に再結合し、派生文章を生成する。
- 原文、原パラメータ、素材IDを保持し、派生結果で上書きしない。
- テスト10/10、Viteビルド成功、5,000件の量子式投影は当該環境で約83ms。

## 別途検討していた機能

1. 本体の意見ネットワークへ量子もつれノードを統合するかの判断。
2. 関連ノードから新しい論点・問い・対立軸を作る「ノードの創出」。
3. 自由記述全体の評価について、結論だけでなく根拠を明示する説明機能。
4. 複数の自由記述、評価、意見チャンクを統合して「つまり」を算出する要約機能。
5. 自由記述本文そのものを扱う入力・保存・匿名化・再評価経路の設計。
6. 完全一致を超えた表記ゆれ・類義語の統合と、統合前データを失わない展開機能。

これらは未実装候補であり、この固定コピーへ後付けしない。
