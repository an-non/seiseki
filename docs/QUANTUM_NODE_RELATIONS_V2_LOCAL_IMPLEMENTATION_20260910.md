## 1. 実装目的

現行Aが生成した量子もつれノード同士について、継承した意味構造、ステータス、出典を使って関係を計算し、その関係から一段だけ二次問題ノードを発生させる。

量子観測処理ではAIを呼ばない。数式は意味を創作するためではなく、根拠のある関係が観測条件によってどの程度強く見えるかを計算するために使う。

## 2. 段階別の実装結果

### 段階1: 比較可能な量子診断

同じ周辺確率を持つ次の三状態を比較する。

- `rho`: 位相を含む純粋なBell型状態
- `rhoD`: 位相干渉を除き、分岐確率と古典相関を残した状態
- `rho_i x rho_j`: 各部分の周辺状態を独立にした状態

診断値は次の二つを分離して保存する。

```text
I = P(rho) - P(rhoD)              # 位相干渉による差
J = P(rho) - P(rho_i x rho_j)     # 独立処理との差
```

観測ベクトルは次の表記を直接使う。

```text
|v> = cos(a)|0> + exp(i beta) sin(a)|1>
```

したがって、既存Aの回転角表記へ読み替える場合だけ角度は `2a` になる。式の意味を変えず、表記差による二重変換を避けた。

### 段階2: 量子ノード同士の関係

現行Aの各量子ノードから次を継承する。

- 対象、行為、条件、トピック、観点、態度、感情、主張
- 切実度、意欲、妥当性の平均・分散・件数
- 全出典ID、表示文に採用されたノードID、観測キー

意味語は照合用に正規化するが、出典IDは原表記を変えず保持する。

関係の強さは意味上の接点を先に求め、ステータス差は補正としてのみ使う。数値が近いだけのノード間に関係を新設しない。

関係は複数の側面を同時に持てる。主表示の優先順位は次の通り。

```text
対立 > 分野横断 > 条件差 > 整合 > 構造的関係
```

干渉の正負で、賛成を反対へ、反対を賛成へ変更しない。

### 段階3: 二次問題ノードの発生

関係候補ごとに次を計算する。

- `evidence`: 出典へ戻れる根拠性
- `structuralNovelty`: 一件の再表示ではない構造的新規性
- `observationDependence`: 観測条件による干渉差
- `mainIssueConnection`: 主要問題への接続度
- `coreAffinity`: 政治核へ近づける表示用の親和度

独立した出典が二件以上あり、各閾値を満たす場合だけ二次問題ノードを作る。同じ出典から派生した量子ノード同士では作らない。

再帰深度は1に固定した。二次問題ノードから次のノードを自動発生させない。

### 段階4: 既存5,000件デモとの接続

既存Aの入力生成、重複統合、複素振幅観測をそのまま通した後、Bへ接続した。

- 入力: 5,400件
- 重複統合後: 5,000件
- 量子ノード: 72件
- B関係線上限: 256件
- 二次問題ノード上限: 24件
- 5,000件互換テスト単体: 約0.36秒
- A+B全テスト: 22件成功、0件失敗
