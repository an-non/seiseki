# 量子もつれ観測: 現行仕様・計算系・ユキ案

- 作成日: 2026-09-07
- 対象実装: `local/quantum-entanglement-engine.mjs`
- 状態: 古典計算による可視化プロトタイプ。本物の量子計算機、量子通信、物理実験ではない。

## 1. 目的

SEISEKIの意見ノードを、固定された唯一の分類として見せるのではなく、観測軸と観測回によって所属、距離、関係、再構成文が変化しうる対象として表示する。

ここでいう「量子もつれ」は物理現象の再現ではない。ベル型二準位系、Born則、位相、結合度、観測基底という量子力学の語彙と数式を、意見間の相関を再観測する決定的な古典アルゴリズムへ写像したもの。

## 2. 入力ノード

各ノードは少なくとも次を持つ。

- `id`: ノード識別子
- `text`: 自由記述から抽出された意見文
- `topicId`: 元の主要トピック
- `candidateTopicIds`: 観測時に移りうる候補トピック
- `entanglementKey`: 相関グループ
- `urgency`, `motivation`, `validity`: 0から100の評価値
- 任意の構造化要素: `topicLabel`, `target`, `lens`, `statement`

文字列はNFKC、空白圧縮、小文字化で正規化し、完全一致するノードを一つへ統合する。統合後も出典ID、元トピック、出現数は失わない。

## 3. 観測基底

評価値を0から1へ正規化し、基底ごとの重みでスコアを得る。

```text
s_i = clamp(w_u * urgency_i/100
          + w_m * motivation_i/100
          + w_v * validity_i/100, 0, 1)
```

| 基底 | `(w_u, w_m, w_v)` |
|---|---|
| 総合 | `(0.5, 0.3, 0.2)` |
| 切実度 | `(1, 0, 0)` |
| 意欲 | `(0, 1, 0)` |
| 妥当性 | `(0, 0, 1)` |

## 4. 相関グループと結合度

`entanglementKey`が同じノードを一群とする。キーがない場合だけ、正規化文字列の決定的hashから72群へ仮配置する。

群平均とのパラメータ類似度は次式。

```text
similarity_i = clamp(1
  - (|u_i-u_bar| + |m_i-m_bar| + |v_i-v_bar|) / 300, 0, 1)

group_coupling = clamp(0.38 + 0.56 * mean(similarity_i), 0.38, 0.94)
node_coupling_i = clamp(group_coupling * (0.55 + 0.45 * similarity_i), 0, 1)
```

似た評価値を持つ同一群ほど、観測時に同じ側へ動きやすい。

## 5. 古典相関モード

群の近接確率を次のように定める。

```text
p_near = clamp(0.12 + 0.76 * mean(s_i), 0.08, 0.92)
```

`seed + epoch + basis + group/node id`から決定的疑似乱数を作り、群ビット、各ノード固有ビット、結合を採るかを決める。結合が成立したノードは群ビットを共有する。同じ入力、seed、epoch、basisなら同じ結果になる。

## 6. 複素振幅モード

一群を決定的に左右の論理分岐へ分け、ベル型状態を使う。

```text
|psi> = cos(theta)|00> + exp(i*phi) sin(theta)|11>
theta = (pi/4) * group_coupling
```

左右の平均スコアを観測角へ写像する。

```text
a = (leftScore  - 0.5) * pi
b = (rightScore - 0.5) * pi
```

各側へY軸回転相当の基底変換を適用し、`00`, `01`, `10`, `11`の複素振幅を計算する。各結果の確率はBorn則で得る。

```text
P(xy) = |A_xy|^2 / sum(|A|^2)
```

実装が併記する指標は次の二つ。

```text
concurrence = sin(2 * theta)
entropy = -p log2(p) - (1-p) log2(1-p)
p = cos(theta)^2
```

これは入力ノードが物理的に量子もつれしている証明ではない。群の結合強度を量子状態風に表す観測モデル。

## 7. 観測後の位置・所属・関係線

観測重みは、個別値、群平均、観測ビット、揺らぎから得る。

```text
observedWeight_i = clamp(
  0.68 * s_i
  + 0.22 * groupScore
  + (bit_i ? 0.09 : -0.09)
  + 0.08 * jitter_i * (1-coupling_i), 0, 1)
```

中心からの距離は高い観測重みほど短くなる。

```text
distance_i = d_min + (1-observedWeight_i)^1.28 * (d_max-d_min)
```

方向は、観測トピック方向50%、ノード固有方向34%、群相関方向16%を混合して単位化する。関係線は同じ観測トピック内の位相順と、群内の近接関係から作る。線強度は結合度と距離差で減衰する。

## 8. 量子もつれノードの文章

各群から観測重み、結合度、Born確率、決定的揺らぎを用いて最大3件を選ぶ。同じ正規化文章は重ねない。

- 構造化要素が揃う場合: トピック、対象、観点、主張を決定的に再構成する。
- 揃わない場合: 元文の短い引用断片を最大3件組み合わせる。
- `sourceNodeIds`と`observationKey`を保持し、どの観測から生じたか追跡可能にする。

AIはこの再構成には使わない。意味の正しさを新しく推論する処理ではなく、既に抽出された要素のローカル再配置である。

## 9. 現行仕様の限界

- 物理学上の量子優位性や非局所性を実証しない。
- `entanglementKey`や候補トピックが妥当でなければ、結果も妥当にならない。
- 再構成文は政策提言、民意、真実、統計的代表性を意味しない。
- hash由来の揺らぎは再現性のある演出であり、真の乱数ではない。
- 観測軸の切替は視点変更であって、元DBを書き換えない。

## 10. ユキ案

本実装へ進める場合も、原ノードを破壊せず、観測結果を別レイヤーとして扱う。

1. 原ノード、AI解析値、原文由来の要素を不変の観測前データとする。
2. 観測結果は `seed`, `epoch`, `basis`, `mode`, `sourceNodeIds`, 数式代入値を持つ一時投影とする。
3. 利用者へは「何が変わったか」を、所属変更、距離変化、関係線差分、再構成文の出典として示す。
4. 再構成文を新しい意見としてDBへ自動採用しない。保存する場合は明示的な候補状態にする。
5. AIを追加するなら、計算後の説明だけを任せ、位置・所属・関係線の決定性はローカル計算に残す。
6. 「つまり」機能とは統合しない。「つまり」は自由記述全体と集計から概要や政策提言候補を作る別機能とする。
7. 本番昇格条件は、決定性試験、出典追跡、空群・単一群・大量ノード試験、操作説明、誤解を招かない表示名の受入とする。

推奨名称は、内部では `correlated observation` / `amplitude observation`、UIでは「相関観測」/「量子式観測」。物理的量子もつれそのものと誤認させない注記を小さく常設する。
