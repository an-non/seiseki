# 声析(SEISEKI)— 政治意見 量子化プラットフォーム

**バージョン: v0.15.2** — アンケートと自由記述で寄せられた政治意見を端末内の規則解析で「感情」「妥当性」「切実度」「意欲」などのパラメータへ量子化し、匿名の統計データとして蓄積・可視化するWebアプリのプロトタイプです。解析時に自由記述を外部AIへ送信しません。スマホ・PC対応の単一ファイルReactアプリです。

## v0.15.2の改修

- **チャンクリンクの説明可能性** — 独立プレビューの線は抽出チャンク本文の共通語を主条件にし、トピック・対象・分類・事実性を補助条件として表示します。チャンク選択時には、相手の本文とリンク根拠を確認できます。

## v0.15.1の修正

- **APIレス解析** — Anthropic API呼び出しを、決定的なローカル規則解析へ置換しました。文分割、最大5件の意見チャンク、政策トピック、カテゴリ、対象、感情・切実度・意欲・推定座標を既存の保存形式で生成します。
- **意見ツリーの表示不具合を修正** — 旧フォールバックが `chunks: []` を保存していたため、回答があっても意見ネットワークが空になる問題を解消しました。新規回答は直ちにネットワークへ反映されます。
- **旧データの明示的な補完** — 管理画面の「旧簡易解析を補完」は、「自由記述あり・旧簡易解析・チャンク空」の回答だけを再解析して集計します。通常の「集計を再構築」は回答を変更しません。
- **空状態と説明を改善** — ネットワークが空でも白紙にせず、原因と補完手順を表示します。同意文はv1.3へ更新しました。

## 主な機能

- **属性クロス集計** — ダッシュボードで、選択中の設問の回答構成比を回答者属性(年代・性別・地域・職業・支持政党)ごとに積み上げ帯グラフで比較できます。「年代 × 政権支持」のように、どの層でどの回答が多いのかを一目で把握できます。
- **時系列トレンド** — 日別(日本時間)の回答から、政権支持の構成比の推移と、平均パラメータ(感情ポジ度・妥当性・切実度・意欲)の推移を折れ線グラフで表示します。期間は7日・30日・90日・全期間から選べます。
- **回答の撤回(セルフサービス)** — 送信完了画面で発行される回答IDを使い、回答者自身がいつでも自分の回答を削除できます。画面下部のフッターリンクから撤回画面に進み、IDで該当回答を照会・確認のうえ削除すると、統計も自動で再計算されます。管理画面からも回答ID指定での個別削除に対応しました。
- **セキュアな設計の強化** — プロンプトインジェクション対策、入力・設定のスキーマ検証、回答IDの形式検証などを追加しました。詳細は `docs/SECURITY.md` を参照してください。

## 使い方(動作確認手順)

アプリを開いたら、まず「管理」タブで合言葉 `admin` を入力して解錠し、「デモデータ投入(9件)」を押します。架空の回答9件(政治的立場が偏らないよう構成/約30日に分散した日時)が保存され、統計が生成されます。

次に「ダッシュボード」タブで、以下を確認できます。

- **設問別の回答分布** と **属性クロス集計**(属性チップで年代・性別などを切り替え)
- **回答グループ別パラメータ**(例:「支持しない」を選ぶとそのグループの平均パラメータと全体平均のレーダー比較)
- **時系列トレンド**(期間チップで7日〜全期間を切り替え)
- **イデオロギー分布**・**意見トピック**・**不満対象別の統計**・**属性内訳**

「意見一覧」タブでは抽出済み意見チャンクをカテゴリ・対象・キーワードで絞り込めます。

実際の解析を試すには「回答する」タブから同意 → 属性 → 設問 → 自由記述と進み、「端末内で解析して送信」を押します。外部通信なしで結果画面にパラメータ・推定座標・意見チャンクと **回答ID** が表示されます。この回答IDを使えば、フッターの「回答の撤回」からいつでも自分の回答を削除できます。

> **既存データからの移行**: クロス集計等の不足だけなら「集計を再構築」を実行します。API失敗後の旧簡易保存で意見が表示されない回答は「旧簡易解析を補完」を実行してください。後者だけが対象回答の解析欄を更新します。既に管理画面で同意文を保存している環境は自動上書きされないため、外部AI送信の記載が残っていないか確認し、必要ならv1.3相当へ改訂してください。

## バージョン管理の方針

動作する実装一式はバージョンごとに `versions/vX.Y.Z/` に凍結保存し、機能変更のたびに新しいバージョンとして切り出します。現在のトップレベル(`app/` `core/` `tests/`)は最新版 v0.15.2です。変更履歴は `CHANGELOG.md` を参照してください。
